## 🚀 Features
* **Cross-Platform UI:** Modern, dark-themed GUI built entirely in Python using Flet.
* **Targeted Web Scraping:** Integrates the Adzuna API to fetch real-time job openings.
* **Geographical Precision:** Users can set a specific city and search radius (km) using an interactive slider, or toggle to search the entire country.
* **Dynamic Keyword Persistence:** Users can add/remove specific technical skills. Keywords are saved locally via JSON persistence so they remain available on the next launch.
* **Automated Reporting:** Cleans the scraped JSON data using Pandas and exports a beautifully formatted Excel (`.xlsx`) report directly to the same folder as the .exe file.
